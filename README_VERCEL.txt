JEJUM DE DESESPERO — VERSÃO SEM FORMULÁRIO

A jornada abre diretamente, sem inscrição, sem recolha de nome, email ou telefone.

INSTALAÇÃO / PUBLICAÇÃO
1. Extrair este ZIP.
2. Publicar todos os ficheiros e pastas na raiz do projeto GitHub ligado à Vercel.
3. Remover a pasta api/inscricao.js anterior do repositório (já não é usada).
4. Aguardar novo deployment na Vercel.
5. No telemóvel, abrir https://jejumdedesespero.vercel.app/ no Chrome (Android) ou Safari (iPhone).
6. Usar o botão de instalação. Se não aparecer convite nativo, usar menu do navegador > Instalar aplicação / Adicionar ao ecrã principal.

Não requer Resend nem variáveis de email na Vercel.
O diário e o progresso são guardados localmente no navegador.
Nota: instalação efetiva depende do navegador e da publicação HTTPS correta.
